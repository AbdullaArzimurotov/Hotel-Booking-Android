# «Гостиница» — HotelCoursework

Курсовая работа Арзимуротова А.М., ПИН-123. Android/Kotlin, Ktor, PostgreSQL.

## Текущий результат: этап 2, Android 0.2.0

Реализован интерфейс с четырьмя разделами: «Поиск», «Места», «Брони» (бронирования),
«Профиль». Работают навигация, выбор страны/города, диапазона дат и гостей, фильтры,
сортировка, карточки гостиниц, галерея, избранное и предварительный расчёт номера с услугами.
На широком экране используются боковая навигация и двухколоночный каталог.

**Каталог пока локальный и демонстрационный**: 36 вымышленных гостиниц, 30 вымышленных
городских мест, 3 страны, 6 реальных городов. Сведения и иллюстрации не описывают настоящие
объекты. Наличие номеров не проверяется, расчёт не подтверждает окончательную стоимость.
Каталог и картинки доступны без интернета; это ещё не Room-кеш серверных данных.
Избранное и форма восстанавливаются при пересоздании приложения, но не хранятся в SQL.

Сохранена платформа этапа 1: Ktor 0.1.0, PostgreSQL, Flyway, реальная проверка соединения.
Она доступна через «Профиль → Диагностика системы» и независима от локального каталога.
**Вход, SQL-каталог, заказы, демооплата, PDF, карта и администратор ещё не реализованы**.
Никакая бронь или внешний заказ в этой версии не создаётся.

Подробности проверки: [этап 2](docs/STAGE_2_VERIFICATION.md),
[этап 1](docs/STAGE_1_VERIFICATION.md), [соответствие заданию](docs/REQUIREMENTS.md).
Происхождение изображений и промпты: [ASSETS.md](docs/ASSETS.md).
Проверено: 20 Android unit + 13 UI + 4 backend теста; UI выполнен в телефонном и
планшетном размере одного API 36 AVD. Lint: 0 ошибок, 1 рекомендация обновления Gradle.
Это не заменяет итоговые испытания на трёх разных виртуальных устройствах.

## Быстрый запуск на этом Mac

**Сейчас проект уже открыт и настроен в Android Studio**: конфигурация `app`,
устройство `HotelCoursework API36`. Нажмите зелёную кнопку **Run** справа от `app`.
Выполнится сборка APK, установка и открытие `MainActivity`. UI-каталог этапа 2 не требует
ручного запуска сервера. Сервер нужен только для «Профиль → Диагностика системы».
Не выбирайте конфигурацию тестов вместо `app`.

Если открываете проект заново:

1. Откройте **папку `android`** в Android Studio: File → Open. Дождитесь Gradle Sync.
   При запросе Gradle JDK выберите встроенный JDK Android Studio (jbr-25).
   Не открывайте `HotelCoursework` как самостоятельный Android Gradle-проект.
2. В терминале перейдите в папку `HotelCoursework` и выполните:

   ```sh
   python3 scripts/dev.py server
   ```

   Команда сначала запустит отдельный PostgreSQL и затем Ktor. Терминал оставьте открытым.
   Внешнее окно Postgres.app запускать не требуется; используются его установленные бинарные файлы.
3. В Android Studio выберите созданный `HotelCoursework_API36` (Pixel 6, ARM64, API 36)
   и нажмите Run для конфигурации `app`.
   Откроется экран поиска. В «Профиль → Диагностика системы» должны появиться
   «Система готова» и два значения «Подключено».
4. Для независимой проверки в другом терминале:

   ```sh
   python3 scripts/dev.py smoke
   ```

Для остановки сервера нажмите Ctrl+C в его терминале. Остановка базы:

```sh
python3 scripts/dev.py stop-db
```

База не удаляется. Следующий запуск использует те же данные. Пока сервер остановлен,
диагностика покажет сообщение и повторную проверку, а локальный каталог продолжит работать.

## Как проверить новый интерфейс

1. «Поиск»: измените направление, даты и гостей, нажмите «Найти гостиницы».
2. В результатах задайте звёзды, рейтинг, бюджет, удобства или тип номера; измените порядок.
   Цены сравниваются внутри одной страны и одной валюты. Стоимость относится к подходящему
   типу номера, а не к самому дешёвому номеру, если он не вмещает гостей.
3. Откройте гостиницу, пролистайте галерею и нажмите на фото для полного просмотра.
4. Выберите «Рассчитать» у типа номера. Дополнительные услуги меняют предварительную сумму.
   Завтрак оплачивается за ночь на номер, трансфер — один раз на группу заказа.
   Бронь при этом не создаётся; параметры рейса появятся на этапе 5.
5. Добавьте гостиницу сердечком и откройте «Профиль → Избранное».
6. «Места»: выберите город и категорию, откройте описание. «Брони» пока показывает честное
   пустое состояние. Кнопка информации об аккаунте объясняет следующий этап, а не имитирует вход.

В форме допускается 1–90 ночей, 1–8 взрослых, 0–4 детей и 1–4 номера. В каждом номере
должен быть хотя бы один взрослый, вместимость учебных типов составляет 2, 3 или 4 гостя.
Календарь использует UTC для преобразования выбранной даты, чтобы избежать сдвига дня.

## Безопасная локальная база

- PostgreSQL 18 установлен в `/Applications/Postgres.app`; существующие базы не затрагиваются.
- Для проекта создается отдельный кластер `.local/postgres`, база `hotel_coursework`,
  несуперпользователь `hotel_app`, порт **55432**, адрес **127.0.0.1**.
- Пароли генерируются автоматически и хранятся в `.local/credentials.json` с правами 600.
  Эта папка исключена из Git. Не отправляйте ее на GitHub.
- TCP и локальный Unix-сокет требуют SCRAM-аутентификацию. Сервер доступен только
  на этом Mac; это не конфигурация публичного production-сервера.
- Скрипт отказывается запускаться поверх чужого процесса на порту или чужого кластера.
- Для другого расположения Postgres.app задайте `HOTEL_PG_BIN`.

## Сборка и тесты

У обоих проектов собственный стандартный Gradle Wrapper 9.2.1. В терминале без настроенной
Java предварительно задайте JDK, который уже поставляется с Android Studio:

```sh
export JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home'
```

Android, из каталога `android`:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
./gradlew :app:dokkaGeneratePublicationHtml
```

Команда `connectedDebugAndroidTest` требует работающий эмулятор. Если подключён также телефон,
выберите AVD переменной `ANDROID_SERIAL=emulator-5554` (уточните серийный номер через `adb devices`).
Тестовый runner может удалить APK после завершения: затем снова нажмите Run в Android Studio.
APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

Backend, из каталога `server`:

```sh
./gradlew test installDist dokkaGeneratePublicationHtml
```

Backend unit/API-тесты не требуют настоящей базы. Команда `scripts/dev.py smoke`
проверяет запущенный сервер с настоящей PostgreSQL через Exposed.
HTML-отчеты тестов и документация Dokka находятся в `build` соответствующего проекта.

## Настройки Android

- compileSdk/targetSdk 36, minSdk 26.
- Эмулятор обращается к Mac через `http://10.0.2.2:8080/`.
- HTTP разрешен только для этого адреса и только в debug-сборке.
- Release использует адрес-заглушку `https://hotel.invalid/`: публичного сервера пока нет.
  Для реального развертывания адрес должен быть заменен на собственный HTTPS API.
- На физическом телефоне `10.0.2.2` не является адресом Mac; этот этап проверяется на AVD.
- Для другого Mac измените игнорируемый `android/local.properties` или дайте Android Studio
  создать его автоматически. SDK-путь не хранится в Git.

## Структура

- `android` — UI/Domain/Data, Hilt, Navigation Compose и Ktor Client.
- `server` — REST API, HikariCP, Exposed JDBC и Flyway.
- `gradle/libs.versions.toml` — общие фиксированные версии зависимостей.
- `scripts/dev.py` — безопасный запуск локальной базы и сервера, smoke-проверка.
- `docs` — API, состояние этапов, соответствие заданию и протокол проверки.

Локальный Git-репозиторий готовится к GitHub. Публикация выполняется только в выбранный
пользователем репозиторий; адрес удаленного репозитория и учетные данные пока не заданы.
Не включайте в коммит `.local`, пароли, SDK-пути, signing keys и Maps API-ключ.
