# APK «Гостиница» 0.9.0

Дата сборки: 05.10.2026. minSdk 26, targetSdk 36, versionCode 9.

## Какой файл установить

- `Гостиница-0.9.0-offline-signed.apk` — подписанный самостоятельный APK, около 20 МиБ.
  Обычная установка на телефон без Android Studio, ноутбука и интернета.
  Package: `ru.arzimurotov.hotel.offline`.
- `Гостиница-0.9.0-debug-update.apk` — обновление существующей debug-установки с этого Mac,
  package `ru.arzimurotov.hotel`. Используйте install -r, не удаляйте приложение/данные.
  Debug-ключ другого компьютера может отличаться: не обходите конфликт удалением данных.
- `HotelCoursework-0.6.0-debug.apk` — сохранённый старый server-вариант, не итоговая версия.

Файлы APK выдаются отдельно от Git: исходный код находится в репозитории.
Для готового signed APK не требуется конфигурация базы или внешнего сервиса.
Для компиляции из исходников сначала нужны Android Studio/SDK и интернет для Gradle Sync.

## Начальный доступ

| Роль | Логин | Пароль |
|---|---|---|
| ADMIN | admin@hotel.demo | HotelAdmin!2026 |
| USER | client@hotel.demo | HotelClient!2026 |

При первом входе сохраните индивидуальный код восстановления. Демо-адреса не являются
почтовыми ящиками. Для писем можно зарегистрировать собственный email.
Все услуги и платежи учебные, каждая установка хранит независимую SQLite-базу.
Письмо подготавливается в Gmail/Mail.ru; отправку подтверждает пользователь.
