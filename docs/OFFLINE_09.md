# Самостоятельная «Гостиница» 0.9.0

## Что установлено в APK

APK содержит SQLite (Room), начальные данные, фотографии-иллюстрации и шесть небольших
offline-карт центральных районов. Первое открытие работает без интернета. Ноутбук,
PostgreSQL, Ktor, API-ключи, банковский счёт и Google billing не требуются.
Интернет не переключает источник данных: та же база телефона используется всегда.
Заказы других телефонов не синхронизируются. Это независимая учебная система,
а не коммерческий сервис общего бронирования. Реальные деньги не списываются.

## Войти

| Роль | Логин | Начальный пароль |
|---|---|---|
| Администратор | admin@hotel.demo | HotelAdmin!2026 |
| Клиент | client@hotel.demo | HotelClient!2026 |

Демо-адреса не являются настоящими почтовыми ящиками. Можно зарегистрировать свой email.
После изменения пароля используйте новый; seed не сбрасывает пароль при запуске/обновлении.
При первом входе сохраните индивидуальный код восстановления вне телефона.
Его показ переживает перезапуск процесса до нажатия «Я сохранил код»; затем в базе остаётся
только хеш. Профиль → «Изменить пароль» требует текущий пароль и выдаёт новый код.
«Забыли пароль?» требует email и сохранённый код. Старый код после использования
недействителен. Без пароля и кода обходного способа нет. Переустановка с удалением данных
не восстанавливает заказы и аккаунты; не выполняйте её для обновления.

## Пройти основной сценарий

1. Выберите страну/город, будущие даты и гостей. Интервал 1–90 ночей, 1–4 комнаты
   одного типа, 1–8 взрослых и 0–4 ребёнка; каждой комнате нужен взрослый.
2. Найдите гостиницу, откройте подходящий тип. Цена и наличие проверяются по всей
   поездке, а не отдельно на день заезда. Цена вводится в валюте страны без конвертации.
3. Выберите услуги. Завтрак начисляется за ночь и комнату; разовая услуга — за заказ.
   Трансфер требует аэропорт, рейс, местное время встречи и телефон. Машина реально не вызывается.
4. ONLINE_DEMO сохраняет резерв на 15 минут. В «Брони» выполните демооплату.
   PAY_AT_HOTEL сразу подтверждает заказ, но оставляет оплату невыполненной.
5. Смотрите активные заказы/историю. Отмена подтверждённого заказа допускается до
   сохранённого срока (в seed за 24 часа до заезда). Демооплата аннулируется только в demo-базе.
6. Откройте HTML-подтверждение; сохраните или подготовьте письмо с вложением.

Часы устройства задают время деморезерва и отмены. Изменение системного времени влияет
на результаты; это ограничение локальной демонстрации, не защита от коммерческого мошенничества.
Заезд 14:00, выезд 12:00 в часовом поясе города. Истёкшие резервы исключаются при проверке,
даже если приложение не работало. Закрытие приложения не останавливает течение 15 минут.

## Письмо и документы

В профиле можно заново открыть приветственное письмо. После успешной демооплаты
появляется неизменяемое подтверждение первоначального платежа. Если он позднее аннулирован,
актуальный статус смотрите в кабинете. Для PAY_AT_HOTEL документ не утверждает оплату.
Все документы содержат предупреждение о демонстрационном и нефискальном характере.

«Отправить на почту» открывает Gmail/Mail.ru или другой установленный почтовый клиент.
Откорректируйте получателя, если использован demo-логин, и самостоятельно нажмите «Отправить».
Красивый HTML передаётся как вложение, поскольку почтовые приложения по-разному принимают
rich text. Для отправки нужен интернет и настроенный почтовый аккаунт. Если клиента нет,
сохраните HTML и отправьте позже. APK не содержит SMTP-пароля и не показывает «доставлено».
Автоматическая отправка и восстановление через email требуют отдельного серверного расширения.

## Администратор

Профиль → «Кабинет администратора». Выберите таблицу: страны, города, гостиницы,
типы/комнаты, тарифы, услуги, удобства, городские места, связи гостиница–место,
закрытые периоды, бронирования или журнал. Ссылки выбираются по названиям.
Суммы вводятся в минимальных единицах: 450000 означает 4500,00 RUB.
Даты конца тарифов и блокировок исключительные. Пересечение активных тарифов запрещено.
Комнату нельзя закрыть на даты действующего заказа. Физический номер уникален в гостинице.
Название/цена/условия существующего заказа не изменяются при редактировании каталога.

Выключение «Активна» архивирует запись, не удаляет историю. Чтобы новая гостиница
появилась, последовательно создайте гостиницу, тип номера, комнаты и подходящий тариф.
Для типа нельзя изменять родительскую гостиницу/категорию после создания.
Фото выбирается системным Photo Picker; импорт ограничен 5 МиБ, уменьшается до 2048 px
и сохраняется JPEG без EXIF. Не нужны разрешения на все фотографии. «Первым» меняет
порядок, «Убрать фото» удаляет ссылку; история бронирований не затрагивается.
Права ADMIN проверяются в LocalEngine/LocalAdmin, не только в интерфейсе.

## Карта

«Места» → «Открыть offline-карту». Выберите город/категорию, нажмите маркер «Г» или «М».
Покрываются только центральные районы шести исходных городов, не весь мир и не вся страна.
Вне покрытия можно прочитать список и координаты. Маркеры гостиниц/учебных мест
демонстрационные; расстояние около гостиницы — по прямой, не маршрут и не время проезда.
OSM-данные распространяются под ODbL; источник/bbox/SHA-256 — assets/maps/manifest.json.
Mapsforge 0.25.0 не обращается к tile-server; map-файлы поставляются с APK.

## Mac / Asus / Android Studio

Клонируйте весь репозиторий, затем откройте папку android. Gradle JDK — встроенный JBR
Android Studio (здесь JBR 25), SDK API 36. Выберите app и устройство, нажмите Run.
Ни server, ни scripts/dev.py server запускать для версии 0.9.0 не нужно.
Windows: `cd android; .\gradlew.bat :app:assembleDebug`.
Mac: `cd android; ./gradlew :app:assembleDebug` при корректном JAVA_HOME.
Первый Gradle Sync требует интернет для библиотек; готовый APK — нет.
Данные телефонов и локальные PostgreSQL-базы Mac/Asus независимы, Git переносит только код.
Backend, V1–V5 и документы 0.6.0 сохранены для изучения старой client-server реализации.

## APK и ключ подписи

Distribution release имеет package `ru.arzimurotov.hotel.offline`, чтобы установка не
требовала удалить старую debug-версию `ru.arzimurotov.hotel`. Это два независимых
пространства данных; перенос PostgreSQL-аккаунтов/заказов в SQLite автоматически не выполняется.
Для обновления существующей debug-установки используйте debug APK из этого Mac
(`adb install -r`), подписанный её прежним ключом. Не применяйте uninstall/clear data.
Готовый release подписан отдельным приватным ключом и устанавливается обычным способом.
Последующие release-обновления должны иметь тот же package, тот же ключ и больший versionCode.

Приватные `.local/hotel-distribution.jks`, `.local/signing.properties` и пароль
не находятся в Git. Сделайте шифрованную резервную копию вне репозитория;
для подписания с Asus передайте приватную папку безопасно, не через публичный GitHub.
Без неё debug сборка работает, release будет неподписанным и не предназначен для установки.
Ключ не восстанавливается из APK: при утрате нельзя безопасно обновить установленные release.
