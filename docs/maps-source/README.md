# Исходные данные встроенных карт

Шесть `.osm.gz` - точные исходные OSM XML-фрагменты, использованные для map-файлов
APK 0.9.0. Они доступны для использования под ODbL 1.0 с атрибуцией
**© OpenStreetMap contributors**. Это отдельные картографические данные, не база
вымышленных гостиниц и не исходный код приложения.

Данные: https://www.openstreetmap.org/copyright
Лицензия: https://opendatacommons.org/licenses/odbl/1-0/
Границы и источники: `android/app/src/main/assets/maps/manifest.json`.
Извлечение и генерация: `scripts/prepare_offline_maps.py` и `scripts/maps-tool`.
Дата подготовки: 05.10.2026. Карты покрывают лишь центральные районы.
Публичный OSM tile-server не использовался; приложение не скачивает тайлы.

Mapsforge 0.25.0 применяется как неизменённая библиотека; её исходный код и лицензии:
https://github.com/mapsforge/mapsforge/tree/0.25.0
https://github.com/mapsforge/mapsforge/blob/master/COPYING

Перед дальнейшим распространением сохраняйте эти уведомления и доступность исходных
данных карт. Не удаляйте атрибуцию из интерфейса. Расширять bbox до всей страны через
публичный OSM API нельзя: используйте подходящие открытые региональные выгрузки.
