# Этапы реализации

Работа выполняется последовательно, с проверкой результата каждого этапа.

1. **Платформа**: Android/Ktor/PostgreSQL, сборка, connection screen, миграция,
   Git, тесты и инструкция. Результаты фиксируются в STAGE_1_VERIFICATION.md.
2. **Дизайн**: четыре раздела «Поиск», «Места», «Бронирования», «Профиль»,
   формы и карточки, навигация, временный репозиторий для разработки UI.
3. **Данные и вход**: география, каталог, роли, JWT, профиль.
4. **Поиск**: даты, гости, фильтры, актуальные свободные номера из API.
5. **Заказы**: транзакции, блокировки, идемпотентность, услуги и трансфер.
6. **Демооплата**: срок резерва, история, отмена, PDF, сохранение и печать.
7. **Места**: городской каталог, связь с гостиницами, Google Maps и Room.
8. **Администратор**: CRUD каталога, тарифов, доступности и разрешенных статусов.
9. **Приемка**: unit/API/UI-тесты, три ARM64 AVD, Dokka, APK, GitHub, скриншоты.

Версия 1 содержит учебные гостиницы в реальных городах: Ташкент, Самарканд,
Москва, Санкт-Петербург, Стамбул, Анталья; 36 гостиниц (по две каждой категории
3, 4 и 5 звезд в каждом городе). Русский интерфейс. Реальные платежи отсутствуют.

После версии 1, отдельно: демобилеты, демотакси и демобронирование автомобилей.
Перед расширениями обновляются требования и архитектура, а не изменяются молча.

Уточнения для будущего обновления PDF:

- общий `places` и связь `hotel_places` вместо дублирования места для гостиниц;
- дополнительные поля трансфера в выбранной услуге заказа;
- матрица приемочных AVD: API 30 компактный телефон, API 35 обычный телефон,
  API 36 планшет. Три функциональных прогона еще не проведены.

Текущие PDF сохраняются неизменными до соответствующего этапа проектирования данных.
На этапе 1 новая ER-модель не объявляется реализованной.
