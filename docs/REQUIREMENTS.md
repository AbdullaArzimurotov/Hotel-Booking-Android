# Соответствие индивидуальному заданию — 0.9.0

Арзимуротов А.М., ПИН-123; задание 18.09.2026, срок 11.12.2026.
Тема: мобильное приложение «Гостиница». Реальные услуги/платежи не выполняются.

| Требование | Реализация |
|---|---|
| Android/Kotlin | Compose/Material 3, MVVM, UI–Domain–Data, Hilt, StateFlow/Coroutines, min API 26 |
| Структурированный каталог | Room/SQLite: типы, физические комнаты, площадь, вместимость, удобства, тарифы и услуги |
| Поиск и фильтрация | Весь интервал [checkIn,checkOut), комнаты/гости, цена, рейтинг, звёзды, тип, удобства, расстояние; сортировка/страницы |
| Бронирование | Room.withTransaction: повторная проверка, 1–4 комнаты одного типа, allocation, idempotency, snapshot |
| Дополнительные услуги | За ночь/комнату либо разово; transfer с аэропортом/рейсом/местным временем/телефоном |
| Личный кабинет | Регистрация/вход, профиль, пароль/recovery, активные заказы/история, отмена, HTML |
| SQL и ADMIN | SQLite; полный локальный CRUD/архив справочников, фото, связи, блокировки, журнал; права на бизнес-уровне |
| Dokka/комментарии | Русские KDoc, генерация Android и сохранённого server |
| GitHub | Полный проект, Windows workflow, исходники карт; приватные ключи/базы исключены |
| Модульные тесты | ViewModel, Domain rules, клиенты; LocalEngineTest на реальном SQLite отдельно от рабочей базы |
| Автоматические UI | Compose и E2E через MainActivity/Hilt/SQLite/Keystore, только указанный AVD |
| ≥3 виртуальных устройств | API 30 компактный телефон, API 35 Pixel 6, API 36 планшет; фактические логи — STAGES_7_9_VERIFICATION.md |
| Структуры/код/скриншоты | Room schema, ER, API и схемы PDF, KDoc, приложение скриншотов |
| Пояснительная записка | RU/EN аннотации, содержание, введение, анализ ТЗ, алгоритмы, руководства, заключение, источники и приложения |

Расширения: 3 страны/6 городов/36 вымышленных гостиниц/30 мест, 15-минутный резерв,
два demo способа оплаты, offline карты, HTML через почтовый клиент.
SQLite соответствует требованию SQL; исходная Ktor/PostgreSQL реализация сохранена.
Общая online база, автоматический SMTP/email reset, билеты/такси/аренда не заявляются.
Протокол отличает выполненные испытания от будущих расширений и не заменяется Xiaomi.
