# Соответствие курсовому заданию

Основание: индивидуальное задание «Мобильное приложение “Гостиница”» и согласованный
план реализации. Этот файл отслеживает требования, а не заменяет итоговый протокол испытаний.

| Требование | Реализация / этап | Состояние после создания платформы |
|---|---|---|
| Android, язык Kotlin | `android/app`, Compose, MVVM, Hilt | Создана платформа приложения |
| Структурированные сведения о гостиницах и номерах | SQL-модель и REST-каталог, этапы 3–4 | Запланировано |
| Несколько стран и городов, гостиницы 3–5 звезд | 3 страны, 6 городов, 36 учебных гостиниц, этап 3 | Запланировано |
| Поиск и фильтры | Серверная фильтрация и экран поиска, этап 4 | Запланировано |
| Бронирование номеров и выбор услуг | Транзакции, проверка доступности, этап 5 | Запланировано |
| Демооплата, подтверждение заказа | Два способа оплаты, нефискальный PDF, этап 6 | Запланировано |
| Личный кабинет и история | Авторизация, профиль, заказы, этапы 3 и 6 | Запланировано |
| SQL-база данных | PostgreSQL, Exposed, Flyway | Реальная изолированная база; предметные таблицы — этап 3 |
| Кабинет администратора | Android-экраны + серверные проверки роли, этап 8 | Запланировано |
| Документация Dokka | Плагин и задачи в обоих Gradle-проектах | Итог генерации фиксируется в протоколе этапа 1 |
| Git и репозиторий GitHub | Локальный репозиторий; публикация в выбранный владельцем GitHub | Публикация еще не выполнялась |
| Модульное тестирование | ViewModel, клиентский репозиторий, конфигурация и API | Тесты платформы созданы; результаты — в протоколе |
| Функциональные испытания на трех виртуальных устройствах | ARM64: API 30 телефон, API 35 телефон, API 36 планшет, этап 9 | Не заменяются одним текущим эмулятором |
| Автоматизированные тесты интерфейса | Compose UI tests; расширение сценариев на этапах 2–9 | Созданы тесты диагностического экрана |
| Итоговые документы и приложения | Алгоритмы, руководства, аннотации, листинги, скриншоты, этап 9 | Первые два теоретических раздела существуют отдельно |

Уточнения практической версии: места объединяются в городской справочник `/places`;
трансфер аэропорт–гостиница входит в дополнительные услуги. Карта и кеш описаний появятся
на этапе 7. Настоящие платежи, реальная доставка пассажиров и выдача действительных билетов
не заявляются. Билеты, такси и аренда автомобилей — отдельные расширения после завершения
гостиничного сценария и обновления архитектурных документов.
