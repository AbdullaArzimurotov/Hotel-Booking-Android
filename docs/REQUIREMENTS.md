# Соответствие индивидуальному заданию — 0.6.0

Основание: задание «Мобильное приложение “Гостиница”», Арзимуротов А.М., ПИН-123,
выдано 18.09.2026; срок проекта 11.12.2026. Завершение этапов 3–6 не означает
выполнение ещё запланированных требований этапов 7–9.

| Требование | Реализация и состояние |
|---|---|
| Android, Kotlin | Compose/Material 3, MVVM, UI–Domain–Data, Hilt, Coroutines/StateFlow |
| Каталог номеров, структурированные условия | PostgreSQL: гостиницы, типы/физические номера, вместимость, площадь, удобства, тарифы и услуги; REST DTO |
| Поиск и фильтрация | SQL: весь интервал, гости/комнаты, цена, звёзды, рейтинг, удобства, тип, расстояние, название; сортировка/пагинация |
| Бронирование | Заказ с 1–4 комнатами одного типа, транзакционная повторная проверка, блокировки, идемпотентность |
| Дополнительные услуги | Завтрак/разовые услуги; трансфер с аэропортом, рейсом, временем и телефоном; снимки цен |
| Личный кабинет | Регистрация, вход, профиль, собственные активные брони/история/отмена |
| SQL и кабинет администратора | PostgreSQL и ADMIN/read-only сводка реализованы; добавление/редактирование через полный кабинет — этап 8 |
| Dokka | Генерация в Android и сервере, русские KDoc и пояснения архитектуры |
| GitHub | Репозиторий Hotel-Booking-Android; Windows CI; данные/секреты не публикуются |
| Модульные тесты | Auth/Browse/Travel ViewModel, REST-клиент, JWT/Argon2/health и скрипты |
| Автоматизированные UI-тесты | Compose, регистрация/профиль, поиск/фильтры, checkout/заказы; безопасный AVD-only runner |
| Не менее трёх виртуальных устройств | Этап 9: API 30 компактный телефон, API 35 обычный телефон, API 36 планшет. Xiaomi не заменяет это требование |
| Структуры данных, программа с комментариями, скриншоты | ER/API/структура/KDoc обновляются; итоговые приложения и набор скриншотов — этап 9 |
| Пояснительная записка | Двуязычная аннотация, содержание, введение, анализ ТЗ, алгоритмы, руководства, заключение, литература и приложения — итоговое оформление этапа 9 |

Расширения плана: 3 страны, 6 городов, 36 вымышленных гостиниц 3–5 звёзд,
30 информационных мест; ONLINE_DEMO/PAY_AT_HOTEL, PDF без фискализации.
Maps и Room — этап 7. Билеты, такси и автомобили не входят в 0.6.0.
Сохранение в SQL — настоящее; услуги, компании и платежи — демонстрационные.
